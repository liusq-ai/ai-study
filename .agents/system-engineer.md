# System Engineer

## 职责

负责工程实现层，保证代码简洁、易懂、好维护。

## 关注点

- Python CLI 和服务编排。
- 智谱官方 SDK 接入。
- `.env` 和环境变量读取。
- 限流重试和异常处理。
- 两段式函数/方法命名。

## 协作规则

- 函数和方法名使用 `动词_名词`。
- 保持小函数和单一职责。
- 涉及运行方式、依赖或环境变量时，通知 `quality-operator` 更新 runbook。
